Fase 2

Almacenamiento Distribuido y Tolerancia a Fallos

Distribución física del dataset consolidado en un clúster Apache Hadoop HDFS con topología de múltiples racks, bloque estándar de 128 MB, factor de replicación 3 y conmutación automática ante incidentes.

Clúster Hadoop HDFS

NameNode coordinador y 4 DataNodes distribuidos en dos dominios de falla físicos (Rack 1 y Rack 2).

Bloques y Replicación 3

División en bloques físicos (BLK-101, 102, 103) triplemente replicados cruzando racks para máxima resiliencia.

Auto-Recuperación

Detección de caída de nodos por timeout de heartbeat y re-replicación inmediata hacia nodos en standby sin downtime.

Colección: db.asistencias

Pipeline de Detección de Faltas y Abandono

$match → $unwind → $group → $project → $sort 
db.asistencias.aggregate([
  // 1. $match: Filtrar sede Lima Norte y período mensual de agosto 2026
  {
    $match: {
      sede: "Lima Norte",
      "registros.fecha_asistencia": { $regex: /^2026-08/ }
    }
  },
  // 2. $unwind: Descomponer el arreglo de marcaciones diarias en documentos individuales
  { $unwind: "$registros" },
  // 3. $group: Consolidar métricas por practicante sumando faltas y horas pendientes
  {
    $group: {
      _id: "$_id",
      nombre_practicante: { $first: "$nombre_practicante" },
      total_faltas_injustificadas: {
        $sum: { $cond: [{ $eq: ["$registros.estado_justificacion", "injustificada"] }, 1, 0] }
      },
      total_horas_pendientes: { $sum: "$registros.horas_acumuladas" }
    }
  },
  // 4. $project: Calcular el campo derivado nivel_riesgo (regla de negocio >= 3 faltas)
  {
    $project: {
      _id: 0,
      practicante: "$nombre_practicante",
      faltas_injustificadas: "$total_faltas_injustificadas",
      horas_pendientes: "$total_horas_pendientes",
      nivel_riesgo: {
        $cond: [{ $gte: ["$total_faltas_injustificadas", 3] }, "Alto", "Bajo"]
      }
    }
  },
  // 5. $sort: Ordenar descendentemente por faltas para priorizar la intervención
  { $sort: { faltas_injustificadas: -1 } }
]);
Insight de Negocio (APM Inversiones): En Lima Norte, los practicantes con 3 o más faltas injustificadas acumulan más del 60% de las horas pendientes sin resolver. La falta injustificada demostró ser un predictor de deserción temprano mucho más confiable que las horas pendientes por sí solas.
Colección: db.incidentes

Pipeline de Severidad y Score Disciplinario

$match → $group → $project → $sort 
db.incidentes.aggregate([
  // 1. $match: Filtrar reportes disciplinarios confirmados durante el mes
  { $match: { estado: "confirmado", fecha: { $gte: ISODate("2026-08-01") } } },
  // 2. $group: Ponderar la gravedad técnica acumulada por practicante
  {
    $group: {
      _id: "$practicante_id",
      total_reportes: { $sum: 1 },
      total_baneos: {
        $sum: { $cond: [{ $eq: ["$tipo_incidente", "baneo"] }, 1, 0] }
      },
      puntaje_gravedad: {
        $sum: {
          $switch: {
            branches: [
              { case: { $eq: ["$tipo_incidente", "baneo"] }, then: 5.0 },
              { case: { $eq: ["$tipo_incidente", "salida_temprana"] }, then: 2.5 },
              { case: { $eq: ["$tipo_incidente", "desconexion_voz"] }, then: 1.5 }
            ],
            default: 1.0 // Tardanzas leves o reconexiones móviles
          }
        }
      }
    }
  },
  // 3. $project: Generar métrica nivel_incidente normalizada para el modelo predictivo
  {
    $project: {
      _id: 1,
      total_reportes: 1,
      total_baneos: 1,
      nivel_incidente: { $round: ["$puntaje_gravedad", 2] }
    }
  },
  { $sort: { nivel_incidente: -1 } }
]);
Aplicación Técnica (Fase 3-B): Pondera la severidad de faltas en Discord y SOFI. Alimenta directamente la variable nivel_incidente y registro_incidentes en los modelos predictivos de continuidad y desempeño mensual.
Colección: db.asistencias

Pipeline de Horas Efectivas vs Cuota (36h/sem)

$unwind → $match → $group → $project → $sort 
db.asistencias.aggregate([
  // 1. $unwind: Descomponer el historial de marcaciones
  { $unwind: "$registros" },
  // 2. $match: Contabilizar únicamente marcaciones validadas o justificadas
  { $match: { "registros.estado_justificacion": { $in: ["asistio", "justificada"] } } },
  // 3. $group: Acumular total de horas efectivas logradas por persona
  {
    $group: {
      _id: "$_id",
      nombre: { $first: "$nombre_practicante" },
      horas_logradas: { $sum: "$registros.horas_acumuladas" }
    }
  },
  // 4. $project: Calcular % de cumplimiento frente a la meta (144 hrs = 36h x 4 sem)
  {
    $project: {
      _id: 0,
      practicante_id: "$_id",
      practicante: "$nombre",
      horas_logradas: 1,
      pct_horas_cumplidas: {
        $round: [{ $multiply: [{ $divide: ["$horas_logradas", 144] }, 100] }, 1]
      },
      estado_cuota: {
        $cond: [{ $gte: ["$horas_logradas", 144] }, "Cuota Cumplida", "Déficit de Horas"]
      }
    }
  },
  { $sort: { pct_horas_cumplidas: -1 } }
]);
Vínculo Predictivo: Alimenta horas_cumplidas_periodo en la matriz de predicción. Practicantes con cumplimiento inferior al 75% presentan 3 veces mayor riesgo de baja calificación o retiro voluntario.
