Fase 2 · Almacenamiento: HDFS

Sistema de archivos distribuido de la empresa

  • Centraliza datos del bot de Discord, SOFI, GitHub Actions y registro de postulantes
  • Diseñado para grandes volúmenes de datos en múltiples servidores
  • Escalabilidad, alta disponibilidad y tolerancia a fallos

Esquema de distribución y segmentación

CriterioParámetro / ReglaJustificación técnica
Tamaño de bloque128 MB Minimiza la sobrecarga de metadatos en el NameNode y optimiza lecturas secuenciales
Factor de replicación3 Soporta la pérdida de hasta dos nodos sin pérdida de integridad
Particionamiento lógicoTemporal (año/mes) y por tipo de origen Estructura /data/raw/{origen}/año=YYYY/mes=MM/ optimiza el filtrado en ingesta
Formato de almacenamientoParquet + Snappy / JSON raw Reduce el almacenamiento y acelera la descompresión en consultas analíticas

Simulación de distribución en el clúster

Dataset consolidado de 320 MB (apm_telemetria_consolidada.parquet) · bloque de 128 MB → 3 bloques físicos

Bloque físicoTamañoRéplica 1Réplica 2Réplica 3
BLK-101128 MBDataNode 1 (Rack 1)DataNode 2 (Rack 1)DataNode 3 (Rack 2)
BLK-102128 MBDataNode 2 (Rack 1)DataNode 3 (Rack 2)DataNode 4 (Rack 2)
BLK-10364 MBDataNode 3 (Rack 2)DataNode 4 (Rack 2)DataNode 1 (Rack 1)

Rack Awareness: las réplicas se distribuyen en distintos racks para evitar puntos únicos de falla.

Tolerancia a fallos · caída de DataNode 2

1El NameNode detecta la ausencia de heartbeats (10 minutos por defecto).

2Identifica que BLK-101 y BLK-102 quedan sub-replicados (factor 2 en lugar de 3).

3Ordena a DataNodes activos replicar los bloques hacia DataNode 4, restaurando el factor 3 sin downtime para las aplicaciones.

Fase 3 · Modelado predictivo

Probabilidad de continuidad del practicante

Problema y objetivo

  • Al finalizar el período, no se sabe quién continuará el siguiente semestre
  • Estimar la probabilidad de continuidad para priorizar ofertas y reducir entrevistas innecesarias

Variable dependiente

  • continuara_siguiente_semestre · binaria (1 = continuará)

Independientes

  • horas_cumplidas_periodo · continua
  • nota_promedio_periodo · continua
  • total_faltas_injustificadas · discreta
  • tipo_justificacion · nominal
  • registro_incidentes · binaria

Acción: si la probabilidad > 70% se prioriza el contacto para ver cupos; si < 30%, baja prioridad y se busca reemplazo.

Fase 3 · Riesgo de bajo desempeño mensual

Problema

  • El bajo rendimiento se detecta tarde, cuando el problema ya ocurrió
  • Se busca intervenir de forma preventiva

Definición

  • Bajo desempeño = promedio mensual ≤ 10/20

Variables

  • bajo_desempeno_proximo_mes · binaria
  • promedio_horas_mes_anterior · continua
  • total_faltas_mes_anterior · discreta
  • justificacion_mas_frecuente · nominal
  • incidentes_registrados_mes_anterior · binaria

Acción: alta probabilidad de bajo desempeño → seguimiento prioritario y análisis de causas para aplicar mejoras.

Fase 3 · Modelado descriptivo

Tablas de negocio para la toma de decisiones

Evaluación del practicante

  • practicante_id, rol, estado_actual
  • nota_promedio_mensual (/20), horas_cumplidas (cuota 36 h)
  • total_faltas, total_justificaciones
  • total_reportes, total_baneos, recuperaciones_pendientes
  • recomendación · Sí / REVISAR / NO

Seguimiento de incidentes

  • tipo_incidente: tardanza, desconexión de voz, salida temprana, baneo
  • nivel_incidente: puntaje según gravedad
  • incidente_mensual: tendencia (sube / estable / baja)

Detecta quienes repiten faltas, prioriza seguimiento urgente y alimenta el modelo predictivo.

Fase 3 · Pipelines de MongoDB

Procesamiento NoSQL y descubrimiento de insights

Objetivo del pipeline: identificar practicantes de la sede Lima Norte con más faltas injustificadas en agosto, para alimentar acciones de retención. 

/* ilustrativo */
{
  "$match": { "origen": "SOFI", "sede": "Lima Norte", "mes": "2024-08" },
  "$group": { "_id": "$practicante_id",
              "total_faltas_injustificadas": { "$sum": 1 } },
  "$match": { "total_faltas_injustificadas": { "$gte": 3 } }
}
"En Lima Norte, los practicantes con 3 o más faltas injustificadas en agosto acumulan más del 60% de las horas de recuperación sin resolver: la falta injustificada es un indicador temprano de abandono, más confiable que las horas pendientes por sí solas."
